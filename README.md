# The Funniest AI Excuse

This repository contains our submission for the make.fun bounty "The Funniest AI Excuse". It features a lightweight Node 22 program that outputs a single deterministic plain-text excuse line detailing an AI agent's humorous rationale after failing a task, requiring zero dependencies or network access. Crafting a concise, perfectly pitched punchline is essential because brevity amplifies the comedic impact of machine failure.

## How to run

To generate the entry file, execute the script with Node.js:

```bash
node main.ts
```

You can optionally specify a custom output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:

```bash
MAKEFUN_OUTPUT_DIR=./dist node main.ts
```
